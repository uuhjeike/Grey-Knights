HOW TO ADD A POST
  1. Write your text.
  2. Paste any links (images, videos, audio, files) on their own line.
  3. Put a single "-" on its own line to END that post.
  4. Save the file and refresh the website.

THE ONLY RULE
  A line containing only "-" ends one post and starts the next.

  Text lines and link lines can be mixed in any order. The website
  keeps your order. Several image links in a row become one gallery.

OPTIONAL DATE
  A line written exactly like 2026-10-07 or 2026-10-07 16:30 becomes
  the post date. Leave it out and no date is shown.

COMMENTS
  Everything between a slash-star and a star-slash (like this block)
  is ignored, and so is any line that starts with two slashes.

PLAIN LINKS WORK
  GitHub links such as
  https://github.com/uuhjeike/Grey-Knights/blob/main/photo.jpg
  are converted automatically. No need to change them to raw links.

POSTS APPEAR IN THE ORDER THEY ARE WRITTEN HERE (top to bottom).
Put your newest post at the top if you want it shown first.
